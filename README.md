# ☕ BROWLETTO CAFE 🍫

An artisanal, high-end cafe website experience featuring immersive video backgrounds, premium glassmorphism design, and smooth GSAP animations.

## 🔗 Live Demo
Experience the sweetness here: **[https://saranshaharwar-code.github.io/BROWLETT-CAFE-/](https://saranshaharwar-code.github.io/BROWLETT-CAFE-/)**

---

## ✨ Features

### 🎥 Dynamic Hero Animations
- **Immersive Video Layer**: Full-viewport background animations that set the perfect artisanal mood.
- **Interactive Switcher**: Instantly swap background videos for **Waffles, Brownies, Shakes, and more** with smooth, high-performance transitions.

### 🎨 Premium Visual Identity
- **Cream-Chocolate Palette**: A sophisticated color scheme using Ivory Cream (#FDF5E6) and Rich Dark Chocolate (#3D1A1A).
- **Luxury Typography**: Elegant use of **Playfair Display** for brand prominence and **Montserrat** for modern readability.
- **Glassmorphism UI**: High-end blurred interfaces for navigation and controls that blend seamlessly with the background visuals.

### 📱 Fully Responsive
- **Mobile-Adaptive**: Custom mobile navigation (hamburger menu) and stacked grid layouts for a seamless experience on any device.
- **Micro-Interactions**: Hover effects, staggered entrance animations, and optimized touch targets.

### 🗺️ Local Presence
- **Interactive Map**: Live Google Maps integration centered on **Amravati, Maharashtra**.
- **Customer Feedback**: Real-time grid of "Sweet Words" from our beloved customers.

---

## 🛠️ Technology Stack
- **HTML5**: Semantic and SEO-optimized structure.
- **CSS3**: Custom properties, Flexbox/Grid layouts, and advanced Blur filters.
- **JavaScript (Vanilla)**: Core interactivity and video management.
- **GSAP (GreenSock)**: Professional-grade scroll animations and smooth UI transitions.

## 🚀 Local Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/saranshaharwar-code/BROWLETT-CAFE-.git
   ```
2. Navigate to the project folder:
   ```bash
   cd BROWLETT-CAFE-
   ```
3. Open `index.html` in your favorite browser.
